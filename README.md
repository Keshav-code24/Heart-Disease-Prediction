# ❤️ Heart Disease Prediction

A Machine Learning web application that predicts the possibility of heart disease using a K-Nearest Neighbors (KNN) classification model.

The application is built with Python and Streamlit and uses feature preprocessing with StandardScaler.

## 🚀 Features

- Heart disease prediction using KNN
- Feature scaling using StandardScaler
- Interactive Streamlit web interface
- Saved trained ML model
- Saved scaler and feature-column information
- Simple prediction workflow

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- K-Nearest Neighbors (KNN)
- StandardScaler
- Pickle

## ⚙️ How It Works

The application follows these steps:

1. **Load Dataset**  
   The `heart.csv` dataset is loaded using Pandas.

2. **Separate Features and Target**  
   The dataset is divided into input features and the target variable.

3. **Feature Scaling**  
   Input features are standardized using `StandardScaler` so that the KNN model can process the numerical values effectively.

4. **Train KNN Model**  
   A K-Nearest Neighbors (KNN) classifier with `n_neighbors=5` is trained on the scaled data.

5. **Save Trained Components**  
   The trained model, scaler, and feature-column information are saved as `.pkl` files.

6. **Streamlit Interface**  
   The Streamlit application loads these saved components and provides input fields for the 44 features.

7. **Prediction**  
   When the user clicks the **Predict** button, the entered values are scaled using the saved scaler and passed to the trained KNN model.

8. **Display Result**  
   The application displays the predicted class on the Streamlit interface.

## 💻 Installation

### Clone the Repository

```bash
git clone https://github.com/Keshav-code24/Heart-Disease-Prediction.git
```

### Navigate to the Project Directory

```bash

```

### Install Dependencies

```bash

```

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser at:

```text
http://localhost:8501
```

## 🧠 Train the Model

To train the model again using the dataset, run:

```bash
python train_model.py
```

The training script generates the following files:

```text
knn_heart_model.pkl
heart_scaler.pkl
heart_columns.pkl
```
